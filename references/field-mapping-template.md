# 字段映射表模板

每张金数据表(form / table)填一份。逐行确认后交给客户签字确认。

## 表:<实体名 / 用途>
- 金数据 form/table 标识:`<form_token 或 table id>`
- 小程序页面:`<列表页 / 详情页>`

| 前端字段(demo) | 金数据字段名 | 金数据字段 key | 类型 | 是否必填 | 读/写 | 备注 |
| ---------------- | ------------ | -------------- | ---- | -------- | ----- | ---- |
| 标题             |              |                | 单行文本 | 是 | 读 | 列表标题 |
| 封面图           |              |                | 图片 | 否 | 读 | 取第一张 |
| 价格             |              |                | 数字 | 是 | 读 | 单位:元 |
| 状态             |              |                | 单选 | 是 | 读 | 上架/下架 |
| 详情             |              |                | 多行文本 | 否 | 读 | 详情页展示 |
| 创建时间         |              |                | 日期时间 | — | 读 | 排序用 |
