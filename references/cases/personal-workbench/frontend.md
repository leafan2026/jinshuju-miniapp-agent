# 个人工作台案例：成品前端与原型移植

以下路径均相对个人工作台演示仓库，不是本 Skill 仓库。按案例当前代码复核后使用，不要求其他小程序实现相同页面和手势。

## 先确定比较对象

读取当前任务涉及的 WXML、页面逻辑、共享 WXSS、组件 WXSS，以及用户给出的原型和截图。原型若只在用户机器上，先核实路径；缺失时不能声称已经比对。当前仓库包含后续日历、抽屉、随笔块编辑与登录改进，不能只按早期 HTML 抹掉这些功能。

如要求“和 HTML 一模一样”，列出页面、组件、状态和操作的对应关系：位置、大小、字号、行高、间距、圆角、线条、图标、选中态、展开态、加载态和返回行为。不要仅移植标题和配色。对照截图应采用相同视口、相同记录、相同日期和相同状态；数量差异先判断数据或时间是否变化。

## 已发生过的布局问题

| 现象 | 检查与处理 | 如何核对 |
| --- | --- | --- |
| 顶部自绘“更多”与微信胶囊重叠、刘海挡住内容 | 当前是 `navigationStyle: custom`；读取胶囊边界与页面 `padTop` 使用处，区分系统区域和业务区域。避免叠加假状态栏/假胶囊。 | 有刘海与无刘海设备都检查首屏和详情返回区。 |
| 添加按钮变成宽条、筛选标签被拉满 | 检查小程序 button 的默认 margin、width、line-height、padding、伪元素边框及 flex 收缩。按组件重置；不是随意把所有按钮设成全宽。 | 新增、筛选、图标按钮分别比较；文字长短均不能挤走旁边内容。 |
| TabBar 宽度、选中底板和底部位置错位 | 看 `custom-tab-bar/` 的盒模型、实际可用宽度、安全区、指示器定位及组件样式隔离；不要只套固定机型截图的偏移量。 | 四个 tab、多个视口宽度、底部 Home 指示条、键盘打开/关闭。 |
| 图标形状和字重不同 | 复用当前 SVG/图标资源和 `utils/icons.js`，不可用 Unicode 字符近似替换原型线性图标。 | 默认、选中、禁用的描边、尺寸和基线。 |
| 字重丢失或元素不显示 | 使用小程序支持的组件与 class。HTML 的 b/em/p/i 及其 CSS 语义不能假设直接等价于 WXML。 | 真正编译模板，并核对文字层级；JS 语法检查不覆盖此问题。 |
| 越改越多全局覆盖、选中态突然失效 | `app.wxss` 有历史主题覆盖；先定位最终生效规则及组件隔离范围。局部修复，避免无验收的大规模重排和继续堆全局 `!important`。 | 同时验证被改组件的普通/选中/禁用态与其他调用页面。 |

尺寸换算要写明采用的逻辑视口。HTML px 与 rpx 不是简单一律乘二：按目标逻辑宽度和小程序 750rpx 坐标换算，固定系统区域使用平台测量；不要混入截图物理像素。保留当前已确认的比例，不能为清理代码擅改已验收布局。

## 沿用组件及行为

- `components/editor-sheet/`：新增和编辑抽屉、分段选择、日期/时间选择、图片选择。使用已有打开、保存、可见性事件；抽屉显示时底栏是否隐藏由现有页面联动。不要改回独立“所有字段手输”的页面。
- `components/completed-stack/`：完成记录堆叠、纵向展开收起与横向恢复。检查实际进度、测量高度和触摸方向，不能拿“一条记录 + 展开文字”代替堆叠。
- `components/workbench-calendar/` 与 `utils/calendar*.js`：真实年月日、选中周、横向翻月/年和纵向月周折叠。保留日期格几何，避免拖动中替换月份造成跳跃。
- `pages/work/`、`project/`、`task/`：保持当前项目展开与详情返回路径、搜索和筛选。任务优先级只改对应字段，完成状态由任务集合派生项目展示；归档项目保持归档。
- `pages/life/`：计划分组、提醒日期、筛选、完成/恢复，与首页“今天的行程”同步。
- `pages/journal/`、`day/`、`note/`：月历图片索引 → 当天记录 → 单篇随笔；沿用换图、切篇与当前 Markdown 块编辑。保留空行、负数/小数/标签文本，不让解析器误当列表或标题。

## 交互验收场景

1. 搜索后切状态/日期、清空搜索、无结果、长标题：列表和计数与当前筛选规则一致。
2. 点击查看后返回：保留正确来源、tab、搜索与滚动位置；不要一律回首页。
3. 轻点、慢拖、快滑、方向反转、纵向滚动、多指、touchcancel：取消不能提交完成，滑后不能误触详情，隐藏/卸载后不能残留动画任务。
4. 抽屉加载中关闭再开另一条、重复点保存、保存中返回、上游报错：不能错填记录、重复写入、关闭后丢失失败现场。
5. 随笔选新图再切篇、只改正文保存、缩略图缓存被回收：不能把前一篇的图片写入后一篇，不重复上传旧图，失效缓存可重新获取。
6. 首屏正常/加载/失败与重试、跨午夜、闰年和月边界：不把静态样机日期当今天；未知错误不渲染成“没有数据”。

`tests/calendar-motion.test.js`、`completed-stack.test.js`、`frontend-data.test.js` 和 `static.test.js` 是行为与绑定回归入口。实际渲染和手感另行验收；未经授权不通过浏览器或其他界面通道绕过用户限制。
