# 个人工作台案例：金数据、缓存及故障定位

以下路径均相对个人工作台演示仓库。表标识只用于解释该案例，不授权对其执行读写；新案例须使用自己的表。

以下是这个项目的实现约定；核实当前代码后再修改，不要把表名、字段名或 Token 套给其他项目。

## 数据事实与入口

| 实体 | Table Token | 服务端映射位置 | 前端标识与关联 |
| --- | --- | --- | --- |
| 工作项目 | `RIqr7K` | `server/index.js` 的 `TYPES.project` | `serialNumber`；项目名称目前参与任务关联 |
| 项目任务 | `tmdXV7` | `TYPES.task` | `serialNumber`；`project` 对应项目名称 |
| 个人计划 | `JZ7FEE` | `TYPES.plan` | `serialNumber`；`when` 是提醒日期 |
| 随笔 | `UTfCnO` | `TYPES.note` | `serialNumber`；`date`、`time`、`image` |

表 Token 放仓库配置。不要要求用户在云托管重复填写四个表 Token；业务凭证仍是服务端秘密。

当前列表读取走服务端金数据 v1 `next` 游标分页；表结构和普通写入走 MCP；图片上传走附件 API 后把附件 ID 写入表。Agent 建表/调整字段使用当前可用的 Jinshuju MCP，工具 schema 以发现结果为准。不能因旧会话提到某个字段就编造 `field_N`、选项值或工具参数。

字段适配位于 `fieldsFrom`、`entryToItem`、`itemToEntry`；`utils/view.js` 负责展示派生。读取选项将内部值转成名称，写入将名称转回当前 choices 值，记录号统一为数字。服务端映射缺失造成的空字段不能由前端静默塞假值掩盖。

项目名关联尚非稳定外键。后端保护重名项目与带任务的直接改名；不要解除保护而不做迁移。单个 `remove('project')` 也不是跨表事务。涉及改名/级联删除先检查调用链、关联记录和用户意图；明确部分成功的恢复步骤，不能假定删除项目会自动删除任务。

## 防止保存后又变回去

沿用前端 `utils/api.js` 的写队列、缓存失效代次、短期更新合并，以及服务端 `loadBootstrap` 的并发合并和失效代次。新页面不要直接调用云托管另造缓存。

- 状态/优先级更新只发送修改字段，避免把过时整条数据覆盖回去。
- 保存失败不把乐观状态当成已持久化；请求结果不确定时先读回核验，再决定恢复，不自动重复创建或删除。
- 旧读请求在保存/注销后返回，不得恢复旧缓存或旧身份数据；读取组件使用请求标识阻止已过期回调。
- 列表必须处理后续分页。遇到重复游标、上游失败或本地安全上限，明确失败，不能缓存截断结果并显示为完整数据。

## 图片链路

小程序通过 `uploadNoteImage` 上传临时云存储原图并生成缩略图；服务端获取临时 URL、受限下载、上传金数据附件，再保存附件 ID。不要把大幅 Base64 图片直接放进普通 `callContainer` JSON。

原图的最终业务存储在 Tables，缩略图是可重建缓存。签名 URL、本地临时路径、云文件 ID 和金数据附件 ID 各有含义，不能互换。图片加载使用 `view.js` 的附件归一化和 `image-cache.js`，处理本地缓存文件已被回收的情况。

换篇清空待上传图；只改文字不提交旧 image 字段。辅助上传失败或业务保存失败时按现有清理规则处理临时文件；保存结果不明时不误删可能已使用的资源。不要扩大下载域名范围来掩盖 URL 错误，检查重定向、MIME、大小和超时保护。

## 以证据分层诊断

| 症状 | 优先只读检查 | 不应直接下的结论 |
| --- | --- | --- |
| `cloud.callFunction … resource is not found` | 本地与正在测试的小程序包是否仍用旧云函数调用。 | 不能让云托管用户去部署云函数。 |
| `callContainer` 找不到服务 | 实际环境、服务名、路径、运行版本、流量和前端配置是否一致。 | 不能直接新建另一个环境或服务。 |
| 缺少 `JINSHUJU_ACCESS_TOKEN` | 报错来自哪个运行版本；该版本是否配置且载入了非空变量、是否多版本分流。只核验是否存在，不输出值。 | 这是变量未读到的证据，不足以断言“旧实例还在跑”；重复部署不替代检查。 |
| 登录 503 / 401 / 429 | `server/auth.js` 配置校验、凭证、限流与 `docs/passphrase-access.md`。 | 不能要求补 OpenID 名单、清空认证或在错误时放行。 |
| 金数据 401 / 403 | 区分工作台自己的响应与上游响应，检查运行凭证、表访问权限、适用的出口白名单规则。 | 截图只见变量名不能证明秘密值有效，也不能断言一切都是 Token 错误。 |
| “全是 0”或字段为空 | 网络错误/响应结构、字段映射、选项值、筛选、分页、缓存及当前日期。 | 不能重新导入假数据或将失败显示成空表。 |
| SSE/JSON 解析报错或假保存成功 | `parsePayload` 按事件处理通知、空响应、JSON-RPC error 及 `result.isError`。 | 不能把多个 `data:` 事件直接拼成一个 JSON。 |
| 图片不显示 | 附件结构、短链有效期、本地文件、云存储权限、包内路径。 | 登录成功不证明图片访问规则正确。 |
