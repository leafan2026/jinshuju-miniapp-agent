# 字段形态参考

这是业务建模参考，不是金数据 API 的固定 schema。实际支持类型、读写结构和字段 key 以当前 MCP/API 核验结果为准。

| 业务含义 | 前端表现 | 必须核验的契约 |
| --- | --- | --- |
| 短文本/长文本 | 标题、说明、正文 | 长度、换行、空值；是否支持所需富文本 |
| 数字/金额 | 计数、价格 | 精度、单位、读写类型；不要假定所有金额都以元存储 |
| 单选/多选 | 状态、分类、标签 | 展示名与实际选项编码、数组形态、清空方式 |
| 日期/日期时间 | 提醒、日历、区间 | 纯日期还是时间点、格式、时区、边界 |
| 图片/附件 | 封面、图集、下载 | 实际对象结构、上传返回的持久标识、URL 有效期 |
| 联系方式/地址 | 文本、联系入口 | 组合结构、校验、脱敏、可见范围 |
| 明细/关联 | 子项列表、归属 | 支持的结构、稳定标识、跨表更新是否需应用协调 |

不要将图片一律解释为 URL 数组，或将所有日期认定为 ISO 时间点。适配层明确输入输出，覆盖实际取得的返回样例与缺失字段。资源访问规则按实际调用方式核验，业务身份验证不自动覆盖附件 URL 权限。
