# 金数据小程序零代码搭建指导 Skill

面向不会写代码的用户，一步一步把业务想法做成 **金数据 Tables + 微信小程序 + 微信云托管** 应用。助手完成代码、配置文件与排错，你描述业务、确认效果，并完成必须本人进行的登录、授权和平台操作。

“零代码”表示你不需要手写业务代码；平台账号、权限及可能产生的服务费用仍需要按实际用途准备。本仓库保存搭建指导与案例经验，具体小程序代码放在独立应用仓库。

## 从这里开始

[SKILL.md](SKILL.md) 是唯一 Skill 入口。将本仓库根目录作为 Skill 包交给支持本地 Skill 的 Agent，保留 `references/`、`assets/` 与入口的相对位置；不要从演示仓库安装。工具如何安装/发现 Skill 以使用者的 Agent 环境为准，本仓库不要求启动额外模型框架。

可以这样描述任务：

> 使用 jinshuju-miniapp，一步一步带我做一个客户查询发货和售后进度的小程序。我不会写代码，请每次只告诉我当前需要做什么，由你完成代码、配置和排错。

需求、样机和模拟测试不需要先交出密钥；MCP、云托管和上传权限在进入对应阶段时准备。没有工具权限时会明确列出尚未完成的真实操作。

默认从用途开始，依次完成：需求 → 样机体验 → 金数据连接与建表 → 开发者工具预览 → 云托管真实联调 → 真机验收 → 体验版及按需审核发布。已有项目从当前步骤继续；每次只处理一项用户操作，已确认的信息不会反复询问。

完整带搭方法见 [逐步带搭手册](references/guided-build.md)。[个人工作台带搭示例](references/cases/personal-workbench/guided-walkthrough.md) 展示如何把一个真实案例变成用户可以跟随的步骤。

## 分享边界

分享 Skill 不等于公开演示系统、授权访问案例表，或许可再次分发所有图片/字体。发布前检查秘密与个人资料、素材授权，以及接收者是否能访问相关仓库。引用不可访问的演示源码时，其验证状态应标明“未核实”，通用流程仍可独立使用。
