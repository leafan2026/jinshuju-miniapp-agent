# 金数据常见字段类型对照

以下为规划字段映射时的参考。**以金数据 `get_form` / `get_table` 返回的实际字段类型与 key 为准**,本表仅帮助对齐前端展示形态。

| 金数据字段类型 | 典型取值 | 前端展示建议 |
| -------------- | -------- | ------------ |
| 单行文本 | 字符串 | 标题 / 标签 |
| 多行文本 | 字符串(含换行) | 详情段落 |
| 数字 | 数值 | 数量 / 计数 |
| 金额 | 数值(元) | 价格,注意精度与单位 |
| 单选 | 选项值 | 状态标签 / 分类 |
| 多选 | 选项值数组 | 标签组 |
| 下拉框 | 选项值 | 分类选择 |
| 日期时间 | ISO 时间字符串 | 格式化展示 / 排序 |
| 图片 | URL 数组 | 封面 / 图集(常取第一张作封面) |
| 附件 | 文件对象数组 | 下载链接 |
| 地址 | 省市区 + 详细地址 | 地址展示 / 地图 |
| 手机 / 邮箱 | 字符串 | 联系方式(注意脱敏与隐私) |
| 评分 / 量表 | 数值 | 星级 / 评分条 |
| 子表单 | 记录数组 | 明细列表(嵌套) |

## 注意
- 图片 / 附件返回的是金数据托管的 URL,小程序需确认域名在合法 request/downloadFile 域名列表内。
- 手机、邮箱、身份证等个人信息字段,展示与存储都要注意合规与脱敏。
- 选项类字段(单选 / 多选 / 下拉)前端要做「金数据选项值 ↔ 展示文案」的映射。
