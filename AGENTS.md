# eve Agent App

This project uses the eve framework. Before writing code, read the relevant guide
from the installed eve package docs. In most installs, those docs are at
`node_modules/eve/docs/`. In workspaces or local package installs, resolve the
installed `eve` package location first and read its `docs/` directory. If
package docs are unavailable, use https://eve.dev/docs as a fallback.

Before changing deployment, cloud-hosting, upload, or credential-handling code,
also read `项目日志.md`. It records reusable delivery failures and invariants;
do not treat it as a release ledger.
