# 个人工作台样机

打开 `personal-workbench.html` 即可预览。它是一个单文件、浏览器内存假数据的交互样机；刷新页面会恢复初始数据。

目录结构：

- `personal-workbench.html`：完整可交互原型。
- `personal-workbench-spec.md`：场景、字段与 CRUD 范围。
- `assets/personal-journal/`：用户授权用于样机的随笔图片。

该样机不连接金数据，不包含凭证，不会上传本地选择的图片。它是早期原型，不覆盖成品后续已确认的交互。见 [个人工作台案例分析](../../references/cases/personal-workbench/index.md)；应用源码与测试保留在独立演示仓库。

图片获准用于本样机不自动代表允许用于其他应用或再次公开分发；分享或改作新案例前核实素材授权，不能确认时移除或换成自有素材。
