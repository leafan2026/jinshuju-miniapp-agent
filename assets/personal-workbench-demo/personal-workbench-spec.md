# 个人工作台小程序 · 交互草样规格

## 目标

为个人使用者建立一个有明确边界的系统：工作项目与任务、生活和学校计划、以及可拍照和写一段话的随笔，最终在首页汇总节奏。

## 页面与动作

1. **首页**：工作项目、本周任务、生活计划的统计；一个聚焦项目和混合日程。日程只展示“工作”或“生活”，随笔不进入日程。
2. **工作**：项目列表；点击进入项目详情，展示项目名称、核心摘要、项目描述、时间范围与任务列表。
3. **生活**：主要容纳学习、健康、关系等个人计划；点击可完成或恢复计划。
4. **随笔**：以完整月历作为索引，带照片的日期表示已有记录；点击日期才进入当天记录。每则记录由一张照片和一段话组成；可拍照/从设备选择图片并写一句话。

## 完整交互范围

- 工作项目：新增、查看、编辑、删除；字段为状态、优先级、开始/结束时间、项目名称、核心摘要、项目内容。
- 项目任务：新增、查看、编辑、删除；字段为状态、优先级、开始/结束时间、任务名称、核心摘要、任务内容。
- 个人计划：新增、查看、编辑、删除；字段为分类、状态、优先级、开始/结束时间、计划名称、核心摘要、计划内容。
- 随笔：完整月历作为索引；点击日期进入当天记录；随笔可新增、查看、编辑、删除，包含标题、正文和一张图片。
- 原型内的所有数据只保存在浏览器内存中，刷新页面后重置为样例数据。

## 原型字段（均为假数据）

| 区域 | 字段 |
| --- | --- |
| 工作项目 | `项目名称`、`核心摘要`、`项目描述`、`时间范围`、`进度`、`核心目标` |
| 工作任务 | `所属项目`、`任务时间范围`、`任务核心摘要`、`任务描述`、`完成状态` |
| 个人计划 | `计划名称`、`计划分类`、`时间范围`、`计划说明`、`完成状态` |
| 随笔 | `记录日期`、`记录时间`、`正文`、`图片`、`归属`、`标签` |
| 首页汇总 | `活跃项目数`、`本周完成任务数`、`本周生活计划数`、`今日安排` |

## 视觉边界

- 390px 移动基准，不绑定某个手机品牌或硬件外观。
- 极简单列结构，以留白与细分隔线建立层级；信息有归属但不堆砌卡片。
- 近白背景、黑色文字、蓝色代表工作进行中、紫色代表生活、绿色代表完成、琥珀色代表临近截止。
- 随笔按完整月历和当天详情浏览；本样机使用用户明确提供的本地图片作为假数据，图片复制在样机目录的 assets/personal-journal/ 中；新增记录仍可选择用户本地图片，原型不上传。
- 后续接入真实数据前，需要由 `jinshuju-schema` 对齐事项、工作流与自动化的实际字段。
